# GTH Experimental Website

God’stime Holdings (GTH) — experimental static frontend build.

## Purpose
This is a separate experimental project and does **not** modify the protected `Idol0264/gth-webapp` baseline.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- Local SVG/CSS graphics
- No backend
- No database
- No server-side authentication
- No API requirement
- GitHub Pages compatible

## Pages
- `index.html` — GTH Home
- `about.html` — About GTH
- `platforms.html` — Ecosystem directory
- `gtf.html` — God’stime Funds
- `gtc.html` — God’stime Channels
- `gts.html` — God’stime Softwares
- `connect.html` — GT Connect

## Important limitation
Any access, membership, security or account-like behavior shown in this project is a frontend demonstration only. It does not provide server-enforced security or real identity verification.

## Deployment
Upload the project contents to a separate GitHub repository and enable GitHub Pages from the repository's Pages settings.
